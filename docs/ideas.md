# Ideas

The ideas list now lives on the project wiki: [Ideas](https://github.com/devlinjunker/train-robber/wiki/Ideas). Its source is [`wiki/Ideas.md`](../wiki/Ideas.md), so add ideas there in a PR, with who raised them and when.

When an idea is scheduled, move it into [requirements.md](requirements.md) or [technical-design.md](technical-design.md) and strike it on the wiki.
